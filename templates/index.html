Cryptographic Security Framework

How the three foundational cybersecurity goals are met in SecureVote.

Confidentiality Protected
RSA Public-Key Cryptography

Ballot selections are transformed into ciphertext integers via modular exponentiation (C = M^e mod n) using the election authority's public key. Network eavesdroppers cannot discern voter choices without the private exponent d.

Integrity & Authentication Verified
HMAC-SHA256 (RFC 2104)

Every submission is authenticated using a 256-bit keyed hash computed over the encrypted payload and voter metadata. Any modification in transit creates an immediate tag mismatch and triggers safe rejection.

Availability Operational
Resilient System Architecture

Availability is supported by application design, schema validation, duplicate-voting prevention, and graceful error handling. If a voter attempts to vote twice or transmits malformed data, the service rejects the request safely without crashing.
