Security Analysis & Threat Modeling

Comprehensive evaluation of the four cryptographic pillars, attack simulation matrix, and real-world electronic voting limitations.

Confidentiality

RSA Asymmetric Public Key

Mechanism: Ballot data is transformed via modular exponentiation ($C = M^e \pmod n$). Network eavesdroppers and database observers see only modular cipher integers.

Secrecy Guarantee

Integrity

HMAC-SHA256 Hash Digest

Mechanism: The 256-bit authentication tag guarantees that the ciphertext was not altered, truncated, or substituted during transit over untrusted networks.

Tamper Resistance

Authentication

Proof of Shared Secret Possession

Mechanism: The tag can only be generated by an entity possessing the voter's unique symmetric key $K$. The server authenticates that the vote originates from an enrolled voter.

Origin Verification

Key Security

Asymmetric Key Isolation

Mechanism: Public key $(e, n)$ is distributed to voters; the private exponent $d$ is kept strictly secret on the server. Voters never learn or expose each other's keys.

ACADEMIC LIMITATIONS

Important Security Disclaimer & System Limitations

As required for academic rigor and viva evaluation, this educational prototype highlights key real-world challenges.

Notice of Educational Scope

"This project is a cryptographic demonstration and not a production-ready election system."

While this prototype demonstrates the mathematical correctness of RSA encryption and HMAC-SHA256 authentication, real-world national electronic voting demands additional specialized security properties beyond basic client/server cryptography:

Voter Anonymity & Receipt-Freeness:

Real elections require that voters cannot prove how they voted to third parties (preventing vote-buying and extortion).

Coercion Resistance:

Ensuring a voter cannot be coerced into revealing credentials or casting a forced ballot at home.

Secure Hardware (HSMs):

Production election authorities protect private keys inside FIPS 140-2 Level 3 Hardware Security Modules.

Secure Key Distribution:

Scalable, trusted infrastructure for distributing pre-shared symmetric HMAC keys to millions of registered voters.

End-to-End Verifiability (E2E-V):

Allowing voters to verify their vote was recorded as cast, and the public to verify all recorded votes were correctly tallied.

Secure Deployment & Side-Channels:

Protection against distributed denial-of-service (DDoS), physical device tampering, and power analysis attacks.
