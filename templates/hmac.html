What HMAC-SHA256 Provides

Integrity & Authenticity: Binds the ballot payload to a shared secret key possessed only by the legitimate voter and the election authority. Ensures that any alteration in transit creates an invalid tag.

Tag Length: 256 bits (32 bytes / 64 hexadecimal characters)
What HMAC-SHA256 Does NOT Provide

HMAC is NOT Encryption: It does not conceal the ballot contents. An observer reading an HMAC tag cannot reverse it, but can read any unencrypted payload. RSA provides confidentiality; HMAC provides integrity.

Constant-Time Digest Verification

When the server verifies incoming ballots, it recomputes the expected HMAC tag and compares it to the received tag using Python's hmac.compare_digest(). Standard string equality (==) short-circuits on the first non-matching byte, leaking timing clues that enable side-channel forgery attacks. Constant-time comparison examines all 32 bytes in uniform time regardless of match position.
