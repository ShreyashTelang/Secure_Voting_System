Section 8: Fundamental Cryptographic Distinctions for Viva

SHA-256 $\neq$ Encryption:

SHA-256 is an unkeyed cryptographic hash function (one-way). It cannot be "decrypted".

HMAC-SHA256 $\neq$ Encryption:

HMAC does not provide confidentiality. An HMAC tag proves authenticity and integrity, not secrecy.

HMAC = Integrity + Authentication:

Integrity (detects modification) + Authentication (verifies possession of the shared secret key $K$).

Why NOT $H(\text{Key} \parallel \text{Msg})$:

Naively concatenating Key + Message is vulnerable to Length Extension Attacks. HMAC solves this via nested inner/outer padding.

RFC 2104 Internal Padding Details:

Step 1
Key Conditioning ($K'$): Key length = 15 bytes (≤ 64 bytes block size). Padded with zeros on the right to $B = 64$ bytes ($512$ bits).
Step 2
Inner Pad XOR: Compute $K_{in} = K' \oplus \text{ipad}$, where $\text{ipad} = \text{0x36}$ repeated 64 times.
Step 3
Inner Hash: $H_{inner} = \text{SHA-256}(K_{in} \parallel \text{Message})$. Produces 32-byte intermediate hash.
Step 4
Outer Pad XOR: Compute $K_{out} = K' \oplus \text{opad}$, where $\text{opad} = \text{0x5C}$ repeated 64 times.
Step 5
Final Digest (Authentication Tag): $\text{Tag} = \text{SHA-256}(K_{out} \parallel H_{inner})$.
